# AuctionChain — Project Overview (Vehicle Sealed-Bid Auction Platform)

**AuctionChain (`Predict · Bid · Verify`)** is a Decentralized Vehicle Sealed-Bid Auction Platform built on Ethereum (Hardhat Chain ID `31337`).
It focuses exclusively on the **Vehicles (`vehicle`)** asset category, combining off-chain LightGBM machine-learning resale valuation in **USD (`$`)** (`v1.0.0`), an on-chain **PriceOracle (`PriceOracle.sol`)**, and a two-phase **Sealed-Bid Commit-Reveal Smart Contract (`Auction.sol`)** settling in **Test ETH (`ETH`)**.
